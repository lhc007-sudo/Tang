# 平台简介

Tang 是面向分子科学计算的一体化桌面平台。用户在 Windows 图形界面中选择结构、方法和输出位置，计算任务则由便携式 WSL2 环境执行。
![Tang 平台整体架构](../_static/1-1.png)
## 设计目标

- **简单使用**：用户不需要在每次计算时手动进入 Linux 或输入长命令。
- **环境隔离**：不同理论模块使用各自的 Python 环境和计算程序。
- **便于迁移**：后端可导出为 rootfs 压缩包，在另一台 Windows 电脑上重新导入。
- **结果可见**：日志和计算文件自动复制回用户选择的 Windows 文件夹。

## 三个计算模块

| 模块 | 当前状态 | 主要后端 |
|---|---|---|
| 电子结构理论 | 可用 | MOKIT/pyphf、PySCF、ZZQ、SRDSE |
| 核运动理论 | 预留 | 尚未启用 |
| 分子动力学 | 可用 | PYGAMD、Numba CUDA |

Tang 的 Windows 前端与 Linux 后端彼此分离。这样既保留 Windows 应用的操作体验，也可以继续运行只支持 Linux 的科学计算程序。
